## Quickstart

To run locally, install:

```bash
brew upgrade gdal
brew install uv
uv sync
```
Now you can run notebooks, make commands, or src directly.

The make commands are dockerised so no need to have installed locally:
```bash
uv run make build
uv run make run
```
